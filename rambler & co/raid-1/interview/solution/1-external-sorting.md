# Решение 1 — внешняя сортировка страниц

Применяется алгоритм сортировки слиянием, адаптированный для работы с внешней памятью
(например, жёстким диском), — внешняя сортировка (External Sorting).

1. Разделение данных на страницы и их сортировка:
   - каждую из 4 страниц данных загружаем поочерёдно в оперативную память;
   - сортируем каждую страницу в памяти (например, `sort.Slice` в Go) и сохраняем
     обратно во временные файлы.

   Теперь есть 4 отсортированных файла: `page1_sorted`, `page2_sorted`, …, `page4_sorted`.

2. Слияние отсортированных страниц в один файл:
   - открываем все 4 отсортированных файла для чтения;
   - создаём буфер для хранения текущих элементов из каждого файла
     (например, по 1 элементу из каждого);
   - находим минимальный элемент среди всех открытых файлов и записываем его
     в итоговый файл;
   - перемещаем указатель в файле, откуда был взят элемент, и считываем следующий;
   - повторяем, пока все файлы не будут полностью прочитаны.
