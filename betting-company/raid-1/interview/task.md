# Бэттинговая компания — заход 1, техническое интервью

- Даты: 2024-07-29
- Формат: онлайн, разбор опыта + две задачи на Go + теория

## 1. Разворот слайса на месте

Написать функцию, которая разворачивает числа в слайсе на месте: `[1 2 3 4 5]` → `[5 4 3 2 1]`. По ходу обсудили: почему достаточно идти до половины; почему передача слайса в функцию по значению не мешает — копируется заголовок, а подложка общая; что пойдёт не так, если в цикле обмена добавить в слайс новый элемент (выход за ёмкость).

## 2. Продюсер и два потребителя

Условие — в комментариях к коду:

```go
// горутина producer чисел
// 2 горутины потребители и полученные числа печатают на экран
// порядок вывода не важен
```

По ходу обсудили: буферизованный или небуферизованный канал выбрать; кто и когда закрывает канал; как main дождаться обеих горутин (WaitGroup, где Add и Done); как совместить ожидание значения из канала с отменой по контексту (select с `ctx.Done()`).
