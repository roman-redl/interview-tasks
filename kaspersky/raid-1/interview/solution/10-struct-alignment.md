# Решение 10 — размер структур и выравнивание

Вывод:

```
equal
```

Обе структуры занимают 24 байта на 64-битной платформе. Компилятор
выравнивает каждое поле по адресу, кратному его размеру, и общий размер
структуры — по её самому широкому полю (здесь `int` = 8):

- `Car1`: `int`(8) + `bool`(1) + паддинг(7) + `int`(8) = 24. После
  одиночного `bool` перед `color` требуется 7 байт паддинга, чтобы `int` лёг
  по адресу, кратному 8.
- `Car2`: `int`(8) + 4×`bool`(4) + паддинг(4) + `int`(8) = 24. Три
  дополнительных булевых флага (`fromChina`, `fromEurope`, `fromUSA`)
  уместились в тот же паддинг, что раньше тратился впустую.

Мораль: одинокий `bool` между двумя `int` «съедает» слот в 8 байт; несколько
булевых полей подряд упаковываются в один слот. Группировка мелких полей
вместе (или размещение их в конце) уменьшает размер структуры — классическая
оптимизация по `unsafe.Sizeof`.
