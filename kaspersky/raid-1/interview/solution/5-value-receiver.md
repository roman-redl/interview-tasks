# Решение 5 — ресивер по значению

Вывод:

```
0
```

Метод объявлен с ресивером по значению: `func (c Count) Increment()`. При
вызове `count.Increment()` копия `count` передаётся в метод, `c++` меняет
копию, оригинал в `main` остаётся нулём.

Чтобы метод менял переменную вызывающей стороны, нужен ресивер-указатель:

```go
func (c *Count) Increment() {
	*c++
}
```

Вызов остаётся тем же `count.Increment()`: переменная `count` адресуемая, Go
сам передаст `(&count)`.
