# WorkerPool

Реализовать пул воркеров: задачи ставятся в очередь (FIFO) и выполняются не более чем `numberOfWorkers` горутинами. Публичный интерфейс:

```go
type WorkerPool struct {
	// ...
}

func NewWorkerPool(numberOfWorkers int) *WorkerPool

// Submit — поставить задачу в очередь и сразу вернуться.
// Если пул уже остановлен, возвращается ошибка.
func (wp *WorkerPool) Submit(task func()) error

// SubmitWait — поставить задачу в очередь и дождаться её выполнения.
func (wp *WorkerPool) SubmitWait(task func()) error

// Stop — остановить пул, не дожидаясь задач из очереди:
// дорабатывают только задачи, которые уже выполняются.
func (wp *WorkerPool) Stop() error

// StopWait — остановить пул после выполнения всех задач,
// включая находящиеся в очереди.
func (wp *WorkerPool) StopWait() error
```
