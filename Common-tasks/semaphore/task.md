# Семафор на канале

Реализовать семафор на буферизованном канале: ограничить число одновременно работающих горутин заданным весом. Методы:

- `Acquire` — занять слот, блокируется при исчерпании;
- `TryAcquire` — занять слот без ожидания, вернуть `false`, если занято;
- `Release` — освободить слот.
