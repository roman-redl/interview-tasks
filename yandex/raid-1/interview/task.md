## 1. Client-side балансировщик нагрузки

Есть приложение с микросервисной архитектурой. Микросервис можно абстрагировать с помощью интерфейса Backend; для доступа к одному экземпляру микросервиса используется тип BackendImpl, который уже реализован.

Для каждого микросервиса есть несколько десятков запущенных экземпляров, каждый из которых доступен по своему адресу addr. Однако отдельные экземпляры микросервиса ненадёжны: они могут падать, быть недоступными либо перегруженными. Поэтому нужно реализовать тип Balancer, который также реализует интерфейс Backend и осуществляет client-side балансировку нагрузки между экземплярами микросервиса:

1. если в течение x времени было n ошибок подряд, экземпляр блокируется на y минут; балансировка — round robin;
2. усложнение: модернизировать и использовать для запросов наименее нагруженные бэкенды.
