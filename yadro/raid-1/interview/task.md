## 1. Укладка коробок

Есть коробки разных размеров и ограниченный объём под них. Например, в отведённое место помещаются две больших коробки, а третья уже не влезает. Требуется предложить алгоритм укладки коробок, при котором свободного места остаётся как можно меньше: остаток объёма после крупных коробок добивается более мелкими.

## 2. Вывод map в порядке убывания ключей

В редакторе открыт код на Go. Требуется доработать его так, чтобы пары ключ-значение печатались в порядке убывания ключей.

```go
func hash() {
	m := map[int]int{1: 1, 2: 2, 3: 3}
	// print key-value pairs
}
```
