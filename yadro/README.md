## Теоретические вопросы (заход 1)

### Linux

- VFS: inode, dentry, superblock; принцип «всё есть файл».
- Чем sysfs отличается от /proc.
- Пошаговая диагностика тормозящего сервиса.
- Сценарий: Postgres отвечает за 50 мс, клиент получает ответ за 2 с — где теряется время.
- Методы IPC в Linux (pipes/FIFO, message queues, shared memory, UDS, TCP); кроссплатформенный IPC.
- Пайпы — FIFO или LIFO.
- epoll и нетполлер Go, парковка горутин.

### Сети

- Уровни и назначение модели OSI (спрашивали дважды).
- Сетевая маска: уровень OSI, назначение, работа через побитовое И.
- Что такое TCP-сокет (5-tuple, гарантии, net.Conn).

### Go

- var против := — отличия, ограничения, зачем два способа.
- Процесс против потока против горутины; зачем горутины, модель M:N.
- Deadlock против race condition.
- В чём непредсказуемость data race.
- Способы защиты общих данных (mutex, atomic, каналы); Mutex против Atomic.
