## 1. Объединение пересекающихся интервалов

Дан массив `meetings`, в котором каждый элемент `meeting[i]` — это пара двух чисел `[startTime, endTime]`. Необходимо объединить все накладывающиеся друг на друга встречи и вернуть массив с объединёнными встречами, покрывающими те же временные слоты.

```text
Input: [[1,3], [2,6], [8,10], [15,18]]
Output: [[1,6], [8,10], [15,18]]
Explanation: Интервалы [1,3] и [2,6] пересекаются => объединяем в [1,6].
```

## 2. HTTP-запросы по списку через каналы
