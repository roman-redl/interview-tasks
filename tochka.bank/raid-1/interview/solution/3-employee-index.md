# Оптимальный и покрывающий индекс

Условие — какой оптимальный индекс и какой покрывающий для запроса:

```sql
SELECT * FROM employee WHERE sex = 'm' AND salary > 300000 AND age = 20 ORDER BY created_at
```

Ответ (с собеседования): оптимальный индекс делается только по age — пол покрывает половину таблицы (низкая селективность), а зарплата — диапазонный предикат. Покрывающий — по всем полям из WHERE.
