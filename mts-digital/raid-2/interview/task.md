## 1. Map и WaitGroup: что выведется

Определить без запуска, что попадёт в консоль. После ответа обсудили: что произойдёт при многократном нажатии Run; почему в коде `struct{}{}` вместо `bool`; почему с конкурентной записью в слайс такой ошибки нет, а с мапой — есть; как физически работает atomic.

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	data := make(map[int]struct{})
	wg := sync.WaitGroup{}
	wg.Add(2)
	go func() {
		defer wg.Done()
		for i := 0; i < 10; i++ {
			data[i] = struct{}{}
		}
	}()
	go func() {
		defer wg.Done()
		for i := 10; i < 20; i++ {
			data[i] = struct{}{}
		}
	}()
	wg.Wait()
	fmt.Println(data)
}
```

## 2. Append в исходный слайс: что выведется

Определить без запуска, что попадёт в консоль. После запуска и разбора вывода — дополнительный вопрос: как исправить код, чтобы цикл прошёл только по исходным шести элементам, если длина слайса заранее неизвестна.

```go
package main

import "fmt"

func main() {
	data := []int{1, 2, 3, 4, 5, 6}

	for i := 0; i < len(data); i++ {
		item := data[i]
		if item%2 == 0 || item%3 == 0 {
			data = append(data, item+1)
		}
	}
	fmt.Println(data)

}
```

## 3. Самые дорогие товары (SQL)

В редакторе дана таблица с товарами и ценами. Написать select-запрос, который выдаст самые дорогие товары — все строки с максимальной ценой (в примере — item3 и item5).

```sql
create table example1
(
    id    serial,
    title text,
    cost  int
);
insert into example1(title, cost)
values ('item1', 10),
       ('item2', 12),
       ('item3', 15),
       ('item4', 10),
       ('item5', 15);
```
