## 2. Rate limiter с корзиной токенов

Реализовать rate limiter, соответствующий интерфейсу Limiter. Основной концепт: для каждого ключа key есть корзина токенов; при вызове метода Allow количество токенов уменьшается на 1. Если количество токенов стало равным 0 — вернуть false, в остальных случаях вернуть true. Токены начисляются с некоторой скоростью, скажем n в секунду для каждого ключа; существует максимальное значение токенов, выше которого они не начисляются.

Пример: максимальное количество токенов для ключа — 5, за каждую секунду начисляется 5 токенов, за каждый запрос списывается 1 токен. Это значит, что можно делать 5 запросов в секунду.

Подсказки интервьюера: многопоточность можно обдумать; горутины здесь не потребуются; можно хранить время последнего захода в функцию по ключу и при новом вызове вычислять дельту между текущим и сохранённым временем и исходя из неё начислять токены; единица расчёта — секунды, при дельте 0 секунд ничего не начисляется.

```go
type Limiter interface {
	Allow(key string) bool
}
```
