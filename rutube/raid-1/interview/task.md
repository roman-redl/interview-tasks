## 1. Авторы без видео (SQL)

По схеме написать запрос: выбрать всех авторов, у которых нет ни одного видео. У автора может быть несколько видео, поэтому простая фильтрация по соединению даёт некорректный ответ. По ходу обсуждали: LEFT JOIN с проверкой на NULL против подзапроса с исключением, что скажет EXPLAIN (две выборки — два seq scan), какие ещё бывают join-типы (anti-join).

```sql
create table video (
    id int primary key
    title text
    duration int
    author_id int fk
)

create table author (
    id int primary key
    name text
)
```

```go
func do(dur int) time.Duration {
	time.Sleep(time.Second * dur)
	return time.Second * dur
}

	...
}
```
