## Теоретические вопросы (заход 1)

### Базы данных

- PostgreSQL против MongoDB: принципиальные отличия, ACID против BASE, различия в способах хранения данных.
- Оптимизация работы с БД: «убрать запрос из цикла»; чтение EXPLAIN — что покажет запрос с подзапросом (две выборки — два seq scan) против LEFT JOIN; какие бывают типы join в плане (anti-join и другие).

### Go

- Как устроены примитивы друг под другом: каналы работают на мьютексах, мьютексы — на атомиках; почему для одиночной переменной выгоднее атомик; что внутри мьютекса.
- Многопоточность: как работает планировщик, вытесняющая многозадачность, по каким ещё причинам (кроме тиков и завершения) горутины переключаются, модель GMP.
