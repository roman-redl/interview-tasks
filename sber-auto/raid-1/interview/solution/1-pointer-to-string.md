# Решение 1 — указатель на строку

Код выведет `http://home`.

В `main` в `setLinkHome` передаётся адрес переменной `link`; запись `*link = "http://home"`
присваивает новое значение по этому адресу. Строка в Go — неизменяемое значение, но здесь
перезаписывается сама переменная целиком, поэтому `main` видит новую строку.
