## Теоретические вопросы (заход 2, техсобес)

### ОС и контейнеры

- Поток против процесса; управление потоками в Linux (clone, NPTL, CFS).
- Распределение 100 потоков на 4 ядра.
- Кто ждёт завершения дочернего процесса (wait/waitpid); зомби-процесс и как от него избавиться.
- Команда просмотра процессов (ps aux).
- Контейнеризация против виртуализации.
- x86-64-контейнер на ARM64 Mac (QEMU, multi-arch).

### Сети

- TCP против UDP; механизмы надёжности TCP (SEQ/ACK, fast retransmit, checksum, window).
- Three-way handshake.
- Сетевой уровень OSI (IP, маршрутизация, ICMP); CIDR-маски.
- Управляющие поля IP-пакета (TTL, Protocol, DSCP, фрагментация).
- Коды Хэмминга; контрольная сумма IP-заголовка.
- Функции сеансового уровня OSI; симплекс/полудуплекс/дуплекс; мультиплексирование.
- Переиспользование TLS-сессий (forward secrecy).
- Передача «на проводе» (витая пара, свитчи).

### Go

- Преимущества горутин перед потоками ОС.
- Поведение планировщика при пустой локальной очереди P (work stealing, netpoller).
- Кооперативная против вытесняющей многозадачности; кто вытесняет горутину (sysmon, SIGURG); кооперативные точки (safe points).
- Стек и куча; escape analysis: когда переменная убегает в кучу.
- Когда GC мешает программе (mark assist, STW, sync.Pool, GOGC).

### Базы данных

- PostgreSQL против ClickHouse.
- ACID и реализация в Postgres (WAL, MVCC); уровни изоляции.
- Сценарий BEGIN → SELECT → UPDATE → SELECT: видимость изменений по уровням изоляции.
- Serializable против Repeatable Read (write skew, SSI).
- Однопоточность Redis; репликация против шардирования Redis; их сочетание в Redis Cluster.
