## 2. Вывод алфавита с заменами

Нужно вывести символы английского алфавита:

- каждая третья буква должна заменяться и вместо неё выводиться индекс;
- каждая пятая буква должна заменяться и вместо неё выводиться буква русского алфавита согласно индексу;
- каждая пятнадцатая — выводить 15 (1 раз).

Напишите код, который выводит алфавит от a до z.

## 3. Агрегация заказов по пользователям

В базе данных интернет-магазина две таблицы:

```sql
CREATE TABLE users (
    id INT PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(100)
);

CREATE TABLE orders (
    id INT PRIMARY KEY,
    user_id INT REFERENCES users(id),
    amount DECIMAL(10,2),
    created_at DATE
);
```

Напишите SQL-запрос, который выведет:

1) имена пользователей;
2) количество их заказов;
3) общую сумму всех их заказов;
4) только для пользователей, сделавших более 3 заказов;
5) отсортировать по общей сумме (от большей к меньшей).

## 4. Платежи обрабатываются по два-три раза (кейс по Kafka)

Устный кейс. Есть сервис платежей, внутри Kafka. Замечаем, что некоторые платежи обрабатываются по два-три раза: человек должен был заплатить 100 рублей — списывается 200–300. При эпиковых нагрузках появляется задержка до 30–40 минут, и в реестре сервиса начинается массовая повторная обработка старых сообщений.

Вопросы: какие могут быть причины и как их исправить; на что обратить внимание при конфигурации консюмеров и продюсеров; что известно про гарантии доставки (at most / at least / exactly once) и идемпотентность продюсера (transactional id, уровни изоляции).
