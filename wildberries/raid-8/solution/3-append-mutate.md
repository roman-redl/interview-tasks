# Решение 3 — append и mutate слайса

Вывод:

```
[0]
[0]
panic: runtime error: index out of range [1] with length 1
```

- Первый `Println` — `[0]`: слайс длины 1 из нулей.
- `appendSlice(nums, 1024)` получает копию заголовка слайса (указатель, len,
  cap). Ёмкость 2 позволяет дописать без реаллокации: 1024 попадает в слот 1
  общего массива. Но присваивание `sl = append(sl, val)` меняет len только
  локальной копии заголовка — в `main` у `nums` остаётся len 1, поэтому
  печатается `[0]`, хотя в памяти под слайсом лежит `[0 1024]`.
- `mutateSlice(nums, 1, 512)` валится: обращение идёт через копию заголовка с
  len 1, а запись по индексу 1 проверяется по длине, не по ёмкости —
  `runtime error: index out of range [1] with length 1`. Буферные слоты за
  пределом len недоступны для индексации.

Итог: append через функцию без возврата нового слайса невидим вызывающему
коду; а слот ёмкости существует в памяти, но обращаться к нему по индексу
нельзя. Чтобы `mutateSlice(nums, 1, 512)` работала, длина слайса должна
быть не меньше 2 — например, вернуть `sl` из `appendSlice` и присвоить его
в `main`.
