# Решение 2 — индекс под запрос

Индекс `create index employees (male, salary, age)` запросу не подходит.

- Колонки `male` в запросе нет вовсе: условие фильтрации по полу записано как
  `sex = 'male'`, а не отдельной колонкой-флагом. Композитный индекс работает
  только по непрерывному префиксу колонок: раз первая колонка индекса не
  участвует в запросе, индекс не используется вовсе.
- Даже после переименования порядок плох: `range`-условие (`salary < $2`)
  должно идти в индексе последним. В `(sex, salary, age)` поиск по
  диапазону `salary` обрезает сканирование: колонка `age`, стоящая после
  диапазона, из индекса уже не сужает выборку — остаётся фильтрация чтением.

Правильный индекс:

```sql
CREATE INDEX ON employees (sex, age, salary);
```

Правило раскладки колонок: сначала все условия на равенство (`sex =`,
`age =` — между собой порядок влияет слабее, чаще первой ставят более
селективную), затем одна колонка диапазона (`salary <`) в самом конце.
