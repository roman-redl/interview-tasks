Интерфейсное значение в Go состоит из двух частей: динамического типа и значения. Функция A возвращает настоящий nil-интерфейс — обе части нулевые. Функция B возвращает интерфейс с типом `*impl` и значением nil: у такого интерфейса заполнена часть типа, поэтому он не равен nil.

- `a == b` — false: у значений разные динамические типы (nil против `*impl`); интерфейсы равны только при совпадении обеих частей.
- `a == nil` — true: обе части нулевые.
- `b == nil` — false: динамический тип `*impl` не нулевой, хотя само значение nil.
